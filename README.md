# C++ Learning

A repository documenting my C++ learning journey through the [Alura](https://www.alura.com.br/) C++ training program.

This repository contains exercises and practical projects developed throughout the courses, focusing on understanding the language, strengthening programming fundamentals, and applying software development best practices.

## Topics Covered

- C++ fundamentals and syntax
- Functions, pointers, and references
- Data structures and STL containers
- Memory management
- Object-oriented programming
- Code organization and modularization
- Compilation and linking
- Namespaces and scope management

## Technologies and Tools

- **Language:** C++
- **Compiler:** GCC / G++
- **Development Environment:** Visual Studio Code
- **Version Control:** Git and GitHub

## Repository Structure

Exercises and projects are organized by course and topic, providing practical examples of the concepts covered throughout the training.

## Purpose

Build a strong foundation in C++ and improve problem-solving, code organization, and software development skills through hands-on practice.
